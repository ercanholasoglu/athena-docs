This repository is the Docusaurus skeleton for Athena's customer-facing documentation site.

The planned documentation architecture includes Getting Started, Concepts, Deployment, Operations, Security & Compliance, API Reference, Tutorials, Changelog, SLA, and Support sections. The first content sprint will add the initial ten customer-ready pages from the approved information architecture.

The documentation site is intentionally separate from the Athena application repository so that documentation updates can ship independently from product code releases.
